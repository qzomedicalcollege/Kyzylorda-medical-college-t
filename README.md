# КВМК — статический сайт

Готовый статический сайт для Кызылординского Высшего Медицинского Колледжа.

## Структура

```text
index.html
style.css
script.js
images/
```

## Запуск

Откройте `index.html` в браузере или загрузите файлы в репозиторий GitHub Pages.

## Технологии

- HTML5
- Tailwind CSS через CDN
- Lucide Icons через CDN
- Минимальный JavaScript без сборки

## Интерактивность

- Полноэкранное мобильное меню
- Анимация статистики
- Scroll reveal анимации
- Модальные окна специальностей и новостей
- Лайтбокс галереи
- Уведомление формы обратной связи
